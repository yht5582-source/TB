## 1. 適用對象與使用情境

適合醫師、住院醫師、醫學生、結核照護團隊、藥師及相關醫療人員，用於：

- 依症狀、影像與病原檢驗整理診斷方向及尚待完成的檢查。
- 比較一般藥敏感療程與符合資格者的短療程，理解限制條件。
- 辨認抗藥性、腎功能不全、透析、免疫抑制及重要藥物毒性需要專家介入的時機。
- 透過病例、考題與心智圖進行床邊教學、小組討論或自我學習。

一般民眾若使用，應以理解流程及準備就醫問題為目的，不宜自行選藥、調藥或停藥。孕婦、兒童、HIV、移植、腹膜透析及複雜肺外結核，尤其需要相關專科共同評估。

## 2. 五分鐘開始使用

1. 開啟[結核病臨床導航](https://yht5582-source.github.io/TB/)。
2. 頁首分為五個分頁：臨床評估、示範病例、自我測驗、心智圖、指引來源。第一次使用可到「示範病例」分頁載入第 1 例，依序走完四個步驟。
3. 切換第 2 例透析病例，觀察短療程資格與 Z／E 劑量間隔如何改變。
4. 再切換第 3 例，於「預後與追蹤」查看空洞合併第 2 個月培養未轉陰的處理提示。
5. 切換到「自我測驗」作答，或到「心智圖」複習決策依據；網址加 `#cases`、`#quiz`、`#map`、`#sources` 可直接開啟對應分頁。
6. 若要重新評估，按「清除重填」；若要保留結果，按「列印摘要」，於瀏覽器列印視窗選擇印表機或另存 PDF。

**載入示範病例會取代目前表單；重新整理網頁會清除本次資料及測驗進度。**

## 3. 四步驟操作說明

### 步驟一：病人與警訊

先填基本狀況，再辨識是否有需要優先處理的急症。

| 輸入群組 | 主要欄位 | 操作重點 |
| --- | --- | --- |
| 基本資料 | 年齡、體重、CrCl、感染部位 | 年齡以歲表示；幼兒可填小數。CrCl 單位為 mL/min |
| 透析 | 血液透析 HD、腹膜透析 PD | 請明確選「是／否」；「尚未確認」不等於未透析 |
| 急症 | 呼吸衰竭／嚴重低氧、休克、大量咳血、新神經缺損 | 出現警訊時優先急診／住院與感控，不應只依門診療程提示處理 |
| 症狀與病史 | 咳嗽、發燒、盜汗、體重減輕、接觸史、既往 TB 治療 | 不需所有症狀都存在才考慮結核 |
| 共病 | 糖尿病、免疫抑制、營養不良、HIV、CD4、ART 相容性 | 影響療程資格、交互作用及監測需求 |

本頁的 CrCl 是供藥物調整使用的輸入值，**目前未內建 Cockcroft–Gault 或 eGFR 換算器**，也不會自動將標準化 eGFR 視為 CrCl。請先確認病人適用的腎功能估計與計量體重。

### 步驟二：病原與診斷

填入影像、AFB 塗片、MTB 核酸、MTB 培養、感染檢測及醫師綜合判定。

- MTB 培養「陽性」是指已確認為結核分枝桿菌群；不能僅因報告有分枝桿菌生長就如此填寫。
- 有些欄位提供「已採檢，待報告」；未檢驗、報告未回及陰性結果應加以區分。
- 「醫師已作臨床活動性結核診斷」代表已綜合症狀、影像／病理及替代診斷，不是單憑 IGRA。
- 「已完成評估並排除活動性結核」是進入潛伏感染治療路徑的重要前提，不能用它來略過尚待釐清的症狀或病灶。

結果會列出目前的診斷定位與下一步檢查，例如補足核酸、培養、藥敏或肺外病灶取材。

### 步驟三：治療選擇

輸入 R、H、Z、FQ 藥敏，以及 Z 可用性、懷孕／哺乳、QT 風險、交互作用、肝病、近期用藥與核心二線藥暴露。

系統依已填資料提供療程方向，並列出成人短療程尚缺的條件。若藥敏未齊，可能顯示「推定藥敏感、等待藥敏」；這不代表已證實對所有藥物敏感。

### 步驟四：預後與追蹤

填寫第 2 個月與第 4 個月後培養、服藥完成情形、ALT 倍數、肝炎症狀及視力異常。

ALT 欄位填寫的是**目前 ALT ÷ 檢驗室正常上限**。例如 ALT 150 U/L、正常上限 40 U/L，應填 `3.75`，不是 `150`。

此步驟將風險因素連結至追蹤行動，而非只給出籠統的「預後好／不好」。急症與毒性警訊可於其他步驟同步顯示。

## 4. 診斷判讀與資料防護邏輯

| 顯示結果／情境 | 目前工具如何處理 | 使用者應核對 |
| --- | --- | --- |
| 病原學支持活動性結核 | MTB 核酸或已鑑定的 MTB 培養陽性時，進入病原支持路徑 | 檢體部位、報告內容、既往治療及藥敏 |
| 臨床診斷活動性結核 | 醫師已完成綜合判定時，提供活動性疾病的療程評估 | 替代診斷、病理及後續治療反應 |
| 疑似活動性結核 | 有相關症狀、影像、AFB 或尚未排除疾病的接觸史，提示進一步檢查 | 陰性檢驗的限制及採檢品質 |
| 潛伏感染評估路徑 | 感染檢測陽性，且已完成活動性疾病排除，才顯示預防治療方向 | 感染源藥敏、適應症及交互作用 |
| AFB 陽性／MTB 核酸陰性 | 提醒 NTM、檢體抑制或技術因素，保留培養與鑑定 | 不將 AFB 直接等同 MTB |
| 既往治療＋核酸陽性，未培養證實 | 提醒殘留核酸與真正活動性疾病的鑑別，不直接判定復發 | 新症狀、影像變化、培養與醫師判斷 |
| 「已排除」卻仍有症狀、疑似影像或病原陽性 | 顯示資料衝突，暫不進入潛伏感染處方方向 | 確認欄位、檢體與檢查時間點 |
| 資料不足 | 保留「尚待評估」或列出缺漏 | 不把未填資料當陰性、正常或無禁忌 |

工具僅檢查已實作的部分衝突，**不會自動發現所有邏輯矛盾、核驗原始報告或判定檢體污染**。不同日期的檢驗與治療前後狀態，仍須使用者自行核對。

## 5. 治療模式與候選資格

### 藥物縮寫

| 縮寫 | 藥物 |
| --- | --- |
| H | Isoniazid |
| R | Rifampicin／rifampin |
| Z | Pyrazinamide |
| E | Ethambutol |
| P（HP 等方案中） | Rifapentine |
| M | Moxifloxacin |
| B | Bedaquiline |
| Pa（BPaL 等方案中） | Pretomanid |
| L | Linezolid |
| C | Clofazimine |
| FQ | Fluoroquinolone 類藥物 |

數字表示該階段月數；例如 `2HRZE／4HR` 為前 2 個月 HRZE、後 4 個月 HR。`P` 與 `Pa` 不同，閱讀方案時須注意。

### 目前提供的主要治療方向

| 情境 | 工具提供的方向 | 需注意的界線 |
| --- | --- | --- |
| 一般藥敏感肺結核 | `2HRZE／4HR`，通常共 6 個月 | 須完成藥敏、服藥與反應評估 |
| 合適成人／青少年肺結核 | `2HPZM／2HPM` 候選；8 週＋9 週，共 17 週、119 劑 | 另經短療程條件審查，不能任意縮短 HRZE |
| 兒童非重症 | 提示可評估 `2HRZ(E)／2HR` | 兒科需確認年齡、非重症定義及兒童劑量 |
| 初始空洞＋第 2 月培養仍陽性 | 標準 6 個月方案通常考慮總療程延至 9 個月 | 並排查服藥、藥敏、吸收及交互作用；不直接套用於 17 週方案 |
| H／R 敏感而 Z 不可用 | 提醒通常需延長方案 | 不可把原方案中的 Z 直接刪掉而不重訂療程 |
| H 抗藥、R 敏感 | 評估 R＋E＋Z＋levofloxacin 的專家路徑 | 需確認 FQ 藥敏、其他藥可用性及腎功能 |
| R 抗藥、FQ 敏感的合適肺結核 | BPaLM 候選 | 由抗藥結核專責團隊確認完整資格 |
| 非重症肺部 pre-XDR | WHO 2026 BPaL 候選方向 | 仍需核心藥敏與適用條件審查 |
| 重症肺部 pre-XDR | WHO 2026 BPaLC 候選方向 | 需審查嚴重度與毒性監測，不自動開立二線劑量 |
| 肺外 R 抗藥結核 | 依部位與核心藥敏個別化 | 不自動指定肺部短療程 |
| 成人腦膜／中樞神經結核 | 延長療程、類固醇及住院專科評估提示 | 多重限制並存時須專科整合，不能只依一行療程文字決定 |
| 潛伏結核感染 | 3HP、4R、3HR；6H／9H 為替代方向 | 須先排除活動性疾病；抗藥接觸者另循專門指引 |

### 成人 17 週方案：本工具的保守篩選

目前實作需同時確認：

- 年齡至少 12 歲、體重至少 40 kg，且為一般肺部路徑。
- H、R、Z、FQ 均填為敏感，且可使用 Z。
- 急症欄位均已確認為「否」。
- 無懷孕、哺乳、QT 風險、尚未解決的重大交互作用或嚴重肝病。
- CrCl 已填且至少 60 mL/min，HD／PD 均為「否」。
- 無已填寫的既往治療或近期結核／FQ 用藥疑慮。
- HIV 陰性，或 HIV 陽性且 CD4 至少 100/μL、ART 相容性已確認。
- 第 2 個月培養未填為仍陽性。

**這是目前程式的保守候選條件，並非宣告每一項不符合都是指引上的絕對禁忌。**例如 CKD、近期暴露或特殊感染部位，可能屬需要專家諮詢的情境；網頁會保留專業審查空間。

成人短療程的「≥12 歲資格」與下方一般成人劑量表的「≥18 歲顯示範圍」是兩件事，請勿混用。

## 6. 成人劑量與腎功能調整

### 參考劑量表何時顯示？

目前僅在活動性疾病、一般標準方案路徑，且符合以下條件時顯示：

- 年齡至少 18 歲。
- 體重在本表的 **30–90 kg** 範圍內。
- CrCl 已填，HD 與 PD 均已明確選擇「是／否」。

30–90 kg 是**本工具計算表的實作範圍**，不是該範圍以外病人不能治療。肥胖、極低體重、肌肉量異常或吸收疑慮，需確認計量體重及必要的治療藥物濃度監測（TDM）。

### 表內計算方式

| 藥物 | 一般腎功能的表內參考 | CrCl <30 mL/min 或 HD 的表內參考 |
| --- | --- | --- |
| H | 5 mg/kg，每日；通常上限 300 mg | 通常維持每日劑量 |
| R | 10 mg/kg，每日；採美國一般標準上限 600 mg | 通常維持每日劑量 |
| Z | 20–25 mg/kg，每日 | 25–35 mg/kg／次，每週 3 次 |
| E | 15–20 mg/kg，每日 | 20–25 mg/kg／次，每週 3 次，採 ATS 參考 |

- HD 日提醒透析後給藥；不同藥物可能需要不同給藥間隔。
- PD 的 Z／E 顯示個別化與 TDM 提示，不直接套用 HD 的數字時程。
- 若已填 Z 不可用，表內不列 Z 劑量。
- 兒童、二線藥及成人 17 週方案的完整逐藥處方，沒有在這張表中自動計算。
- mg/kg 換算不等於可直接開立的錠數；需核對製劑、體重帶、肝病、藥敏及當地規範。
- 表內劑量不會取代急性肝毒性或視神經警訊的停藥評估；出現警訊時應先處理毒性。

## 7. 預後評估與動態追蹤

本工具的「預後」指**辨識不利因素、評估治療反應，並提出下一步行動**。

目前會檢視高齡、嚴重腎病／透析、糖尿病、HIV／免疫抑制、營養不良、空洞／粟粒型病灶、抗藥性、漏藥及培養延遲轉陰。沒有自行將因素相加後換算為個人治癒率、復發率或死亡率。

| 時點／警訊 | 網頁提示的追蹤重點 |
| --- | --- |
| 治療前 | 病原與藥敏、CBC、肝腎功能、HIV、體重、交互作用、EMB 視力與色覺 |
| 每月 | 症狀、體重及劑量核對、服藥支持、副作用與適當的痰培養追蹤 |
| 第 2 個月 | 培養是否轉陰、初始空洞、延遲反應原因及療程是否需重新評估 |
| 第 4 個月後仍培養陽性 | 疑治療失敗；新檢體、重做藥敏、專家重訂方案，不能只加單藥 |
| ALT 有症狀 ≥3×ULN，或無症狀 ≥5×ULN | 立即由醫師評估停用肝毒性藥與替代方案 |
| 新視力／色覺異常 | 立即停 EMB，並由眼科與結核團隊評估 |
| 療程結束後 | 殘餘症狀、影像、肺功能障礙及復發症狀，安排個別化追蹤 |

培養轉陰是有利反應，但不表示可自行提前停藥。「未辨識不利因素」也不等於已完成低風險認證，尤其資料尚未齊全時。

## 9. 四十題測驗與詳盡心智圖

### 測驗

- 第 1–20 題為基礎題；第 21–40 題為高階臨床判斷題；上方進度條顯示已作答比例。
- 可用「跳到題目」選單直接切換，選單標示已答對（✓）或答錯（✗）。
- 每題有四個選項，按「確認答案」後顯示正解、解析及指引連結。
- 未作答不計入已作答題數；完成後顯示總分及基礎／高階分項成績。
- 可用前題／後題複習；確認後答案鎖定，需重新開始才能重作。
- 切換到其他分頁後，本次頁面內的進度仍保留；重新整理即清除。
- 成績僅供學習回饋，不作為臨床能力認證或醫療決策依據。

題目涵蓋檢驗判讀、標準與短療程、LTBI、HD 調整、抗藥性、移植交互作用、肝毒性、治療失敗及預後模型限制；新增 H 抗藥、懷孕、兒童、胸膜結核、感控、HIV／ART 時機與 IRIS、linezolid 與 QT 毒性、DOAC 交互作用、肝毒性重新給藥、抗藥接觸者預防與矛盾反應。

### 心智圖

採多層次文字分支，包含 15 個主題、歸入 4 大區塊（對應評估四步驟），超過 100 個說明節點，並可用關鍵字搜尋（自動展開並標示相符節點）：

- **A｜診斷與辨識**（步驟 1–2）：辨識與感控、逐步建立診斷、檢驗陷阱與鑑別。
- **B｜藥敏與治療模式**（步驟 3）：藥敏與抗藥分類、藥敏感治療模式、抗藥性治療模式。
- **C｜特殊族群與交互作用**（步驟 1、3）：特殊族群與部位、兒童與青少年、懷孕與哺乳、HIV 與 IRIS、藥物交互作用。
- **D｜預防、毒性與追蹤**（步驟 4）：潛伏結核感染、毒性與追蹤、不良反應處置、預後與治療結束。

各層可個別展開／收合，也可全部展開或全部收合；關閉後回到原評估頁，不需跳回其他網站。

## 14. 常見問題

### 為何已填檢驗，仍顯示資料不足或需補檢？

診斷、療程資格與劑量需要不同欄位。系統未整合醫院資訊系統，不會自動知道其他報告；請核對檢體部位、藥敏、治療史及欄位狀態。

### 為何選了「已排除活動性結核」仍不能進入 LTBI？

如果同時有症狀、疑似影像、陽性病原或醫師臨床活動性診斷，程式會提示衝突。這是提醒先核對病況，不是讓使用者反覆改欄位直到得到想要的療程。

### 為何 CrCl 45 的病人仍看到一般 Z／E 每日參考，卻沒有自動通過成人 17 週？

兩者是不同層次的規則：劑量表以 CrCl <30 或透析辨識主要間隔調整；短療程採更保守的 CrCl ≥60 自動候選門檻。CKD 的短療程選擇應先諮詢專家。

### 為何已有體重，卻沒有出現劑量表？

請確認活動性診斷與療程分支、年齡至少 18 歲、體重 30–90 kg、CrCl 及 HD／PD 欄位。抗藥專責路徑與兒童不套用此成人表。

### 為何沒有提供精確存活率或治癒百分比？

目前沒有使用經特定族群驗證且校準的個人風險模型。用已辨識的風險因素及治療反應指導追蹤，比用自訂分數產生百分比更符合本工具的範圍。

### 國際建議是否代表台灣健保或公費一定適用？

不是。藥物可近性、核准條件、公費申請與通報規定需另查疾管署及相關規範；目前未自動連線核定給付資格。

### 為何重新整理後資料不見？

目前未實作持久化儲存。需要保留時，先產生並檢查列印摘要，再依院內規範保管。
